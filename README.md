# Рада директорів

Бізнес-гра для підлітків (і дорослих), у яких є ідея, але немає команди.

Гравець приносить бізнес-ідею, наприклад «хочу пекти булочки», і потрапляє на нараду ради директорів. За столом четверо персонажів, і кожен критично дивиться на ідею зі свого професійного боку:

| Директор | Роль | Про що питає |
|---|---|---|
| **Марта Гривенко**, CFO | Фінансова директорка | Собівартість, ціна, маржа, стартовий капітал, звідки гроші |
| **Тарас Хайпенко**, CCO | Комерційний директор: продавець, керівник продажів і маркетолог в одній особі | Хто купить, скільки таких людей у місті, конкуренти, канали продажу |
| **Ірина Статутна** | Юристка | ФОП, податки, дозволи, санітарні норми, договори, згода батьків |
| **Богдан Цехович** | Директор з виробництва | Технологія, пропорції, обладнання, сировина, скільки штук на день |

Директори не просто ставлять питання по черзі: вони реагують на відповіді гравця і сперечаються між собою, як на справжній загальній нараді.

## Ігрові механіки

- **Шість раундів наради.** Після пітчу директори обговорюють ідею і ставлять 1–2 питання. Гравець відповідає всім або конкретному директору (клік по його місцю за столом).
- **Довіра.** У кожного директора своя шкала довіри 0–100. Конкретні відповіді з цифрами її піднімають, відписки опускають.
- **Бізнес-карта.** Десять блоків (продукт, клієнт, ринок, канали продажу, виробництво, собівартість, ціна, стартові гроші, закон, ризики) відкриваються, коли гравець їх пояснює.
- **Досвід і рівні:** Мрійник → Стажер → Засновник → Підприємець → CEO → Магнат.
- **Досягнення:** «Рахівник», «Знаю свого клієнта», «Цех запущено», «Переконав скептика», «Повна карта» та інші.
- **Картки подій** на 3-му і 5-му раундах: подорожчала сировина, відкрився конкурент, прийшло велике замовлення.
- **Кнопка «Не знаю, допоможіть».** Чесність винагороджується: рада пояснює, як знайти відповідь, і пропонує варіанти.
- **Підказка** за 5 XP.
- **Два режими ради:** «Наставники» (критикують, але допомагають) і «Акули» (жорсткі інвестори).
- **Голосування.** Кожен директор ставить печатку «Вкладаюсь», «Доопрацювати» або «Пас». Гравець отримує оцінку зі 100, сильні сторони, ризики, домашнє завдання на два тижні і підсумкову бізнес-карту. Протокол можна скопіювати.

Прогрес зберігається в браузері, тож засідання можна продовжити після перезавантаження сторінки.

## Як запустити

Потрібен Node.js 20 або новіший.

```bash
npm install
ANTHROPIC_API_KEY=sk-ant-... npm start
```

Відкрий http://localhost:3000.

Без ключа гра теж запускається, але в **демо-режимі**: директори говорять заготовленими репліками, а бізнес-карта відкривається за ключовими словами. Для справжньої дискусії потрібен ключ [Anthropic API](https://console.anthropic.com/).

Налаштування через змінні середовища:

| Змінна | За замовчуванням | Що робить |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | Ключ API. Без нього вмикається демо-режим |
| `PORT` | `3000` | Порт сервера |
| `RADA_MODEL` | `claude-opus-5-5` | Модель Claude |
| `RADA_EFFORT` | `low` | Наскільки довго модель думає перед відповіддю (`low`, `medium`, `high`). `low` дає швидші репліки |

Сайт також можна відкрити як артефакт у claude.ai: тоді директорів озвучує Claude в акаунті того, хто грає, і сервер не потрібен.

## Як це влаштовано

```
server.js              Сервер: роздає public/ і відповідає на POST /api/board
public/index.html      Розмітка трьох екранів: лобі, нарада, голосування
public/css/style.css   Стилі (світла і темна теми, мобільна версія)
public/js/
  characters.js        Директори, блоки бізнес-карти, режими
  prompts.js           Промпти і JSON-схеми для Claude (спільні для браузера і сервера)
  ai.js                Вибір, хто озвучує раду: Claude у claude.ai, сервер або демо-режим
  offline.js           Демо-рушій без ШІ
  avatar.js            Мальовані обличчя директорів із настроями
  app.js               Логіка гри: раунди, довіра, досвід, досягнення, голосування
scripts/smoke.js       Швидка перевірка без мережі
```

Браузер надсилає на сервер лише стан гри (ідею, стенограму, відкриті блоки). Промпт будує сервер, тому сторонній текст не може перетворити сервер на безкоштовний доступ до Claude. Також діє ліміт: 30 запитів за 10 хвилин з однієї адреси.

Перевірка:

```bash
npm run check
```

## Безпека

Промпт просить директорів не давати шкідливих порад і пояснювати, чому незаконні ідеї (алкоголь чи вейпи для неповнолітніх, азартні ігри тощо) не підходять, а натомість пропонувати легальну альтернативу. Неповнолітнім юристка нагадує про участь батьків. Поради в грі навчальні: перед справжнім запуском варто порадитися з дорослими.
