# SPE_sheets

Мої таблиці.

## Сайт «Запитай Романа» (`docs/`)

Сторінка, на якій люди ставлять запитання з фінансової грамотності Роману Кушніру.
Чат працює за принципом PatentBot: бот сам веде розмову, ставить прості запитання
з готовими варіантами відповіді, а людина може будь-коли написати своє. Залежно від
того, хто людина (школяр, студент, батьки…) і чим цікавиться, бот дає коротку відповідь
і посилання на заздалегідь підготовлені завдання.

- `docs/index.html` — сторінка з чатом.
- `docs/data.js` — **увесь контент**: теми, питання бота, відповіді, FAQ і завдання.
- `docs/bot.js` — логіка чату (редагувати не потрібно).
- `docs/styles.css` — оформлення.

### Як додати посилання на завдання

Відкрийте `docs/data.js`, знайдіть потрібне завдання в `TASKS` і вставте посилання в `url`:

```js
{ id: "budget-month", topic: "budget", levels: ["all"], title: "Мій бюджет на місяць", desc: "…", url: "https://docs.google.com/spreadsheets/d/…" },
```

Поки `url` порожній, завдання показується з позначкою «Посилання скоро буде».
Там само в `CONFIG` можна додати фото (`photo`) і контакти (`telegram`, `email`) —
їх бот запропонує, коли не знайде відповіді на запитання.

### Як опублікувати

GitHub → Settings → Pages → Source: *Deploy from a branch*, гілка `main`, папка `/docs`.
Локально — просто відкрийте `docs/index.html` у браузері.
