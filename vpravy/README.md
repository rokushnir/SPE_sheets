# Вправи зі «Щоденників успіху»

Збірка з 167 вправ, зібраних із восьми щоденників Романа Кушніра (SPE школа розвитку).
Кожна вправа займає окрему сторінку A4: мета, коротка інструкція і місце для записів.

## Готові файли (`out/`)

| Файл | Що всередині |
|---|---|
| `vpravy-shchodennyky-uspikhu.pdf` | уся збірка: обкладинка, зміст і 167 вправ |
| `1-samoorganizatsiia.pdf` | Самоорганізація і тайм-менеджмент (17) |
| `2-prodazhi.pdf` | Майстер продажів (18) |
| `3-porozuminnia-z-soboiu.pdf` | Порозуміння з собою (11) |
| `4-svidome-batkivstvo.pdf` | Свідоме батьківство (12) |
| `5-vzaiemyny.pdf` | Взаємини з коханою людиною (34) |
| `6-tvorche-myslennia.pdf` | Творче мислення (63, з них 22 творчі задачі; до 20 є відповіді догори дриґом) |
| `7-sport-i-zdorovia.pdf` | Спорт і здоровʼя (12) |

HTML-версії тих самих файлів лежать поруч — їх можна відкрити в браузері й надрукувати.

## Як змінити вправи

Текст вправ — у файлах `content_*.py` (по одному на розділ), будівельні блоки сторінок — у `blocks.py`,
оформлення — у `style.css`.

```bash
npm install          # один раз: Playwright для друку в PDF
npm run build        # python3 build.py && node render.mjs
```

`render.mjs` перед друком перевіряє, що жодна вправа не вилазить за межі своєї сторінки.
