# Інструкції для Claude

- Кожна сторінка — окремий самодостатній HTML-файл у корені репозиторію (наприклад `money.html`).
- Сайт публікується GitHub Pages з гілки `main`: `https://rokushnir.github.io/SPE_sheets/<файл>.html`. Власний домен `bubbles.sp.org.ua` вимкнено (файл `CNAME` прибрано), бо сайт на ньому не відкривався. Повертати `CNAME` лише після того, як у DNS для sp.org.ua додано запис `CNAME bubbles → rokushnir.github.io`.
- Інтерактивні робочі зошити Bubbles лежать у папці `bubbles/` (`bubbles/<назва>.html` → `https://rokushnir.github.io/SPE_sheets/bubbles/<назва>`); додавай кожен новий зошит карткою на `bubbles/index.html`.
- Після створення сторінки додай її в таблицю в `README.md` і завжди давай користувачу пряме посилання на GitHub Pages.
- Не комітити службові файли (скриншоти перевірок тощо).
- Друк / PDF (для всіх сторінок): верстка для друку має бути щільною — мінімум сторінок A4, без великих порожнин. Якщо на сторінці лишається понад 1/5 вільного місця, щось не так: розтягни графіки чи блоки, щоб заповнити місце, або стисни їх, щоб уміститись. Ховай у друці кнопки, навігацію і поля вводу (показуй значення текстом), зменшуй шрифти й відступи, не лишай заголовок самотнім унизу сторінки. Приклад реалізації з автопідбором висоти графіків — `finshliakh.html` (`fitPrint`).
- Публікація на study.spe.org.ua: кожну нову сторінку також переносити в репозиторій `bubbles` (`_src/spe/<файл>.html`), додавати в `_build/catalog.mjs` і запускати `node _build/study-pages.mjs` (див. `bubbles/CLAUDE.md`). Розділ (`/bi/`, `/biznes/`, `/pidlitki/`, `/taim-menedzhment/`…) і код доступу користувач задає сам в адмінці `https://study.spe.org.ua/admin`; скажи, в який розділ перетягнути, і дай посилання `https://study.spe.org.ua/<розділ>/<id>/`.
