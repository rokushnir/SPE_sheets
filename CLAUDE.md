# Інструкції для Claude

- Кожна сторінка — окремий самодостатній HTML-файл у корені репозиторію (наприклад `money.html`).
- Сайт публікується GitHub Pages з гілки `main` на власному домені `bubbles.spe.org.ua` (файл `CNAME`): `https://bubbles.spe.org.ua/<файл>.html`. Старі адреси `rokushnir.github.io/SPE_sheets/...` GitHub перенаправляє сюди.
- Інтерактивні робочі зошити Bubbles лежать у папці `bubbles/` (`bubbles/<назва>.html` → `https://bubbles.spe.org.ua/bubbles/<назва>`); додавай кожен новий зошит карткою на `bubbles/index.html`.
- Після створення сторінки додай її в таблицю в `README.md` і завжди давай користувачу пряме посилання на GitHub Pages.
- Не комітити службові файли (скриншоти перевірок тощо).
